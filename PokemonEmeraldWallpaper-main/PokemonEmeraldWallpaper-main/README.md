# Wallpaper Animado – Pokémon Emerald (HTML/CSS)

Este é um wallpaper animado inspirado em **Pokémon Emerald**, criado com HTML e CSS, pensado para ser utilizado com o **Lively Wallpaper**.

## Como usar

1. Baixe todos os arquivos deste projeto (incluindo `index.html`, `style.css`, Imagens, etc.).
2. Abra o **Lively Wallpaper**.
3. Clique em **"Adicionar plano de fundo"** 
4. Selecione o arquivo `index.html`.
5. Pronto! Seu novo wallpaper estará ativo.
